## 1. 这是什么

一个**完全跑在你本机**的网文写作工作台。它同时是三样东西：

| 身份 | 说明 |
|---|---|
| **写作工具** | 书架 / 章节管理 / 排版 / 伏笔标注 / 快照，替代"记事本 + 一堆文件夹" |
| **风格引擎** | 采集你自己的作品 → 统计出文风画像 → 生成时自动注入，让 AI 说你的话 |
| **AI 工作台** | 自带密钥接入任意 OpenAI 兼容模型；Agent 模式能自己查资料、写、自检、改 |

**适合谁**：长篇连载作者、需要统一文风的多人协作小组、想把 AI 当"副驾"而不是"代笔"的人。

**不适合谁**：想要"一键生成整本小说"的人。本工具是**辅助**，不是自动写作机。

## 2. 安装与启动

### 方式 A：Chrome / Edge 扩展（推荐，无需服务器）

1. 打开 `chrome://extensions/`（Edge 用 `edge://extensions/`）
2. 打开右上角 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择本项目根目录（含 `manifest.json` 的那一层）
4. 点浏览器工具栏的「码字工坊」图标 → **打开完整工作台**

> 侧边栏（Side Panel）形式的入口也在图标菜单里，适合"边看网页边写"。

### 方式 B：纯本地网页版

```bat
双击 start-server.bat
```

或手动：

```bash
python serve.py            # 默认从 5173 起，端口被占会自动 +1
```

窗口会打印实际地址（形如 `http://127.0.0.1:5173/`），用浏览器打开即可。

> 网页版内置 `/ai/chat` 反向代理，用来绕开浏览器直连大模型的 CORS 限制。

**两种方式的数据是隔离的**（浏览器按"来源"隔离存储），详见 [第 6 节](#6-数据存储与隐私)。

## 3. 界面总览

### 顶栏

```
[码字工坊]  书架   写作台   语料库   ────────  已就绪  [导入] [设置]
              ↑ 当前所在页面：圆角框消失、文字变色并微微放大
```

- **书架 / 写作台 / 语料库**：三个主视图，点 logo 也能回书架
- **导入**：把一整份文本导入成**一本新书**
- **设置**：模型 / 主题 / 排版 / 备份

### 书架

- 竖排书目卡片：封面、书名、梗概（超长自动省略）
- 顶部**检索框**：按书名 / 作者 / 梗概实时过滤，右侧显示 `命中数 / 总数`
- 点一本书 → 弹出**书目浮层**（后方变暗）：查看章节列表
- 点浮层里的章节 → 右侧打开**预览编辑区**（占 2/3 宽），可直接改内容

### 写作台（三栏）

```
┌────────────┬──────────────────────────────┬───────────┐
│ 作品 / 章节 │  排版条 · 章节标题 · 正文     │  AI 辅助   │
│ 设定卡片    │  状态栏（字数 / 目标 / 导出） │  Agent     │
└────────────┴──────────────────────────────┴───────────┘
```

- 左栏：切作品、章节列表（含伏笔 ● 标记）、大纲 / 角色 / 设定 / 伏笔卡片
- 中栏：排版条（字体/字号/行距/缩进/标题）+ 正文编辑器
- 右栏：AI 动作、Agent 模式、语料检索结果

### 语料库

左侧是语料列表与采集入口，右侧是风格画像与检索自检。

## 4. 功能详解

### 4.1 书架与作品管理

- 新建 / 改名 / 删除作品，可设封面、作者、梗概
- 检索：书名 / 作者 / 梗概，大小写不敏感，边打边筛
- 书目浮层里的章节列表可直达预览编辑

### 4.2 章节与写作

- 章节增删、自动保存（停顿约 0.7 秒落盘）、状态栏显示"已保存 hh:mm:ss"
- 实时字数、每日目标进度、近 7 天趋势、作品字数排行
- **快照历史**：手动存一个版本，随时回滚

### 4.3 文本排版

| 项 | 说明 |
|---|---|
| 字体 | 宋体 / 黑体 / 楷体 / 仿宋 / 系统默认 |
| 字号 | 12–28 |
| 行距 | 1.4 / 1.6 / 1.8 / 2.0 / 2.4 |
| **段首缩进** | 0–8 个字符可调（写入真实全角空格，导出即一致） |
| 标题标记 | 选中行点「章标题 / 小标题 / 正文」加或不加 `#` |
| 一键整理 | 按当前设置规范化全文缩进 |

> 按 Enter 换段时会**自动补缩进**；空行不补，避免连续空行被塞满空格。

### 4.4 查找替换

写作台排版条最右的 **「查找」** 按钮（或 `Ctrl+F` / `Ctrl+H`）打开查找栏：

- **范围**：本章 / **全书**
- 上一个 / 下一个、替换、**全部替换**
- 区分大小写可选
- "改人名"这类需求，用**全书**一次搞定

按 `Esc` 或再点一次按钮收起。

### 4.5 设定卡片

四个页签：**大纲 / 角色 / 设定 / 伏笔**。每张卡片有标题与内容，鼠标悬停卡片即可浮窗预览。

**伏笔**额外有两个字段：

- **伏笔文段**：从正文里选一段贴进来（决定虚线画在哪）
- **所属章节**：可选，仅用于在章节目录打一个 ● 标记

### 4.6 伏笔标注

- 命中「伏笔文段」的正文段落，底部会出现**紧贴文字的虚线**（不覆盖首行两格缩进）
- **点击**该段 → 浮出「文段缩略 + 伏笔思路」
- 一条伏笔可标**多段**：多个片段用**换行或分号**分隔（逗号算片段内部标点）
- 每条伏笔可单独**启用 / 取消当前选中**，临时失效而不丢文字

### 4.7 语料库与文风画像（RAG）

1. **采集**：从本书正文采集 / 粘贴文本 / 导入 txt
2. **画像**：自动统计平均句长、短句占比、段长、对话占比、标点习惯、人称分布、高频用语
3. **检索**：中文 bigram 分词 + **BM25** 倒排索引，纯本地
4. **注入**：生成时自动带上「风格画像 + Top-K 相似片段」

> 画像准不准，取决于你喂什么。想让它像你，就采集**你自己真正写的正文**。

### 4.8 AI 辅助

**配置**：设置 → 选预设或手填 `Base URL` / `API Key` / `模型` → 点**测试连接**。

内置预设：DeepSeek / OpenAI / 通义千问 / 智谱 GLM / Kimi / 硅基流动 / 本地 Ollama，也可填任意 OpenAI 兼容端点。

**七个写作动作**：续写 / 润色 / 扩写 / 缩写 / 章纲 / 起名 / 角色卡

**结果处理**：

| 按钮 | 行为 |
|---|---|
| 插入到光标 | 有选区时**替换选区**，无选区时插入 |
| 替换选中 | 用结果替换你选中的那段 |
| 复制 | 只复制到剪贴板 |

> 所有结果**必须你手动采纳**，工具不会自动写入正文、更不会自动发布。

### 4.9 Agent 模式（人在环）

给它一句目标（默认「帮我把这一章写完」），它会自主完成：

```
Plan（自己决定查什么资料）
  → Gather（调用本地工具取证）
  → Draft（分段生成）
  → Critic（自检打分 + 列出问题）
  → Revise（不达标才重写）
  → 产出草稿（等你确认）
```

暴露给模型的 8 个工具：作品信息 / 大纲 / 角色卡 / 设定卡 / 章节列表 / 当前章结尾 / 风格画像 / 语料检索。

三重约束：**最大步数**、**修订轮数上限**、**随时中断**。

### 4.10 Agent 大纲梳理

读已写正文 → 只提炼**重大剧情关键点** → 对比已有大纲 → 检出偏差 → 给出拓展方向与建议大纲。

- **增量**：默认只梳理「上次之后」的新章节，进度自动记录，可重置
- **范围**：仅新增 / 全部 / 最近 N 章
- **偏差处置**：可选「调整大纲以匹配剧情」或「生成剧情修改建议」
- 结果可一键写入大纲卡片

## 5. 操作说明（按场景）

### 5.1 五分钟上手

1. 书架 → **＋ 新建作品**，填书名
2. 写作台 → 左侧「设定」建 1 张**大纲**卡、1 张**角色**卡（Agent 会用到）
3. 直接在正文区开始写
4. 写了几千字后 → 语料库 → **采集本书** → 看画像
5. 设置里配好模型 → 右栏选「续写」生成 → 满意就**插入到光标**

### 5.2 日常写作

- 打开写作台 → 左侧点章节继续写（自动保存）
- 章末想看进度：底部状态栏（字数 / 今日 / 目标）
- 一天结束想留底：`存快照`
- 改人名/术语：排版条最右「查找」→ 范围选**全书** → 全部替换

### 5.3 让 AI 贴近你的文风

1. 语料库 → **采集本书**（或粘贴/导入你以前的作品）
2. 检查右侧画像：平均句长、对话占比、高频用语是否符合你的直觉
3. 生成时工具会**自动注入**画像与相似片段 —— 无需额外操作
4. 不满意就继续加语料：喂得越像你，写得越像你

### 5.4 用 Agent 写一整章

1. 先在左侧准备大纲/角色卡，正文里写一两段开头（给它定调）
2. 右栏点 **Agent 模式** → 填目标（如「续写到 2000 字，收在悬念上」）
3. 点 **参数设置**：目标字数 / 最大步数 / 自检重写轮数
4. 点 **开始**，看「执行过程」实时滚动
5. 跑完在右侧「草稿」区**读一遍、改一改** → `追加到本章` 或 `替换本章`
6. 有审稿意见时，可点 `应用审稿意见` 让它按意见重写

> ⚠️ Agent 只产**草稿**。不点采纳，正文一个字都不会变。

### 5.5 梳理大纲

1. 写作台 → 大纲梳理（Agent 大纲梳理）
2. 选范围：仅新增章节（默认）/ 全部 / 最近 N 章
3. 点 **开始梳理**
4. 看结果分区：与大纲不符 → 建议 → 关键点记忆 → 拓展方向 → 建议大纲
5. 有偏差时选择「调整大纲」或「生成剧情修改建议」
6. 满意就 `把建议大纲写入大纲卡片`

### 5.6 埋与收伏笔

1. 在正文里**选中**要埋的那一段
2. 左侧「伏笔」页签 → **＋** → 「伏笔文段」会自动带上你选中的那段
3. 填「伏笔思路」（打算怎么埋、什么时候回收）
4. 保存 → 正文该段出现虚线；以后**点这一下**就能看到思路
5. 要临时屏蔽（比如还没写到回收）：点 **取消当前选中**（文字保留）
6. 回收完成后想彻底去掉：`清空` 伏笔文段 → 保存

### 5.7 把已有的一本书导进来

1. 顶栏 **导入** → 选择 `.txt` / `.md`，或直接粘贴
2. 填**书名**（选文件时会自动用文件名）
3. 点 **导入为新书** —— 正文里的「第X章」会自动拆成章节
4. 自动切到新书并回到书架

### 5.8 备份与迁移

- **设置 → 导出全部数据** → 得到一个 JSON（含书、章、卡片、快照、设置、语料索引）
- **设置 → 导入备份** → 覆盖式还原
- 想迁移到扩展版/网页版：在来源端导出，在目标端导入

## 6. 数据存储与隐私

**没有后端、没有账号、没有遥测。** 稿件与 API Key 只存在你的浏览器里。

| 项 | 说明 |
|---|---|
| 主存储 | **IndexedDB**（数据库名 `writer_studio`）；不可用时自动降级 `localStorage` |
| 存的表 | `books` 作品 / `chapters` 章节 / `cards` 卡片 / `snapshots` 快照 / `kv` 设置与统计 / `corpus` 语料 / `chunks` 语料分块 |
| 密钥 | 存本机浏览器，**不会上传到任何服务器**（只在你请求模型时作为请求头发给该服务商） |
| 网页版 AI 请求 | 经由本机 `serve.py` 的 `/ai/chat` 转发（仅监听 127.0.0.1） |

### 三个必须知道的坑

1. **网页版与扩展版数据互不相通** —— 浏览器按"来源"隔离存储（`http://127.0.0.1:端口` vs `chrome-extension://ID`）。
2. **网页版换端口 = 看起来"数据没了"** —— `:5173` 和 `:5174` 是两个不同来源。**固定用一个端口**，或用扩展版。
3. **清浏览器数据 = 数据真的没了** —— 清除站点数据 / 用隐私模式都会丢。**请定期「导出全部数据」**。

## 8. 常见问题

**Q：API Key 安全吗？**
只存本机浏览器，不上传。但请注意：Key 会作为请求头发给**你自己配置的模型服务商**，其安全性与计费规则由该服务商决定。

**Q：不配模型能用吗？**
能。书架、章节、排版、伏笔、快照、语料画像全部可用，只有 AI / Agent 需要密钥。

**Q：AI 会自己写进我的正文吗？**
不会。所有 AI 与 Agent 产出都停留在"草稿"区，**必须你手动采纳**。

**Q：伏笔虚线不显示？**
检查三处：①「伏笔文段」填了吗（只认这个字段，不认「所属章节」）②这段文字是否和正文完全一致（两端空白会被忽略）③「启用这段标注」是否勾着。

**Q：导入后章节乱？**
分章按「第X章 / 第N回 / 第X节」识别。识别不到就整份作为一章，之后在章节列表里手动拆。

**Q：模型报错怎么办？**
设置里点**测试连接**先验证通路；再确认模型名、Base URL（多数要带 `/v1`）、余额与网络。
