## 详细描述

```
码字工坊是一套完全跑在你本机的网文写作工作台。没有账号、没有后端、没有遥测——稿件和密钥只存在你的浏览器里。

它同时是写作工具、风格引擎和 AI 工作台。

━━━━━━━━━━━━━━━━━━━━
【写作工作台】
━━━━━━━━━━━━━━━━━━━━
· 书架：竖排书目目录（封面 / 书名 / 梗概），支持按书名、作者、梗概实时检索
· 章节管理：增删章节、自动保存、实时字数、每日目标、近 7 天趋势、作品字数排行
· 快照历史：手动存版本，随时回滚，防止手滑
· 设定卡片：大纲 / 角色 / 设定 / 伏笔 四类卡片，悬停即可预览
· 文本排版：字体、字号、行距、段首缩进（0–8 字符可调）、标题标记、一键整理缩进
· 主题：默认 / 护眼绿 / 护眼蓝 / 暗色，还可自定义主色
· 导入导出：导入 txt / md 直接生成一本新书（按「第X章」自动拆章）；导出单本 txt、全量 JSON 备份

【查找替换】
写作台工具栏一键打开，支持本章与全书两种范围——统一术语、批量改人名一次完成。

【伏笔标注】
选中正文里的一段话，写上「伏笔思路」，该段落底部就会出现贴合文字的虚线；以后点击这一段，就能看到当初埋它的用意。一条伏笔可以同时标多段，也可以单独启用或临时取消。

━━━━━━━━━━━━━━━━━━━━
【RAG 文风贴合 · 核心能力】
━━━━━━━━━━━━━━━━━━━━
· 采集你自己的作品作为语料
· 本地统计出风格画像：平均句长、短句占比、段长、对话占比、标点习惯、人称分布、高频用语
· 中文 bigram 分词 + BM25 倒排索引，检索全部在本机完成，不上传任何语料
· 生成时自动注入「风格画像 + 最相似的过往片段」，让模型说你的话，而不是通用腔

━━━━━━━━━━━━━━━━━━━━
【AI 辅助 · 自带密钥】
━━━━━━━━━━━━━━━━━━━━
· 支持 DeepSeek / OpenAI / 通义千问 / 智谱 GLM / Kimi / 硅基流动 / 本地 Ollama，也可填任意 OpenAI 兼容端点
· 七个写作动作：续写、润色、扩写、缩写、章纲、起名、角色卡
· 结果必须你手动采纳，工具不会自动写入正文
· 「插入到光标」在你有选中内容时会替换选区，符合编辑器的通用直觉

【Agent 模式（人在环）】
给它一句目标，它会自己决定查哪些资料、分段写、写完自检打分、再按问题修订，最后交给你一份草稿：
  Plan → Gather → Draft → Critic → Revise → 草稿
暴露给模型 8 个本地工具（作品信息 / 大纲 / 角色卡 / 设定卡 / 章节列表 / 当前章结尾 / 风格画像 / 语料检索）。
三重约束：最大步数、修订轮数上限、随时中断。

【Agent 大纲梳理】
读取已写正文，只提炼重大剧情关键点，对比已有大纲并检出偏差，给出拓展方向与建议大纲。支持增量梳理（默认只处理上次之后的新章节），偏差可选择「调整大纲」或「生成剧情修改建议」。

━━━━━━━━━━━━━━━━━━━━
【隐私与设计边界】
━━━━━━━━━━━━━━━━━━━━
· 纯本地：稿件与密钥只存你的浏览器（IndexedDB），无后端、无遥测
· 自带密钥：模型由你自己申请与配置，本扩展不提供模型服务
· 不注入第三方网站：没有内容脚本，不读取你访问的网页
· 不自动发布、不自动回写：AI 结果只进编辑框
· 不提供「去除 AI 痕迹」功能：不涉及隐藏、规避或伪造生成事实
· 本地记录 AI 调用日志，方便你按平台要求主动声明

⚠️ 补充说明：只有当你点击「生成」时，提示词（及命中的风格片段）才会发送给你自己配置的模型服务商；不点就不会有任何网络请求。

本扩展为独立开发的开源项目（MIT 许可），与任何第三方平台或模型厂商无隶属关系。
