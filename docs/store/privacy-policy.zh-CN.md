# 隐私政策 · 码字工坊 Writer Studio

**最后更新：2026-10-09** ｜ 适用版本：v0.1.0 及以上

---

## 一句话概括

**开发者不收集你的任何数据。** 你的稿件、设定、语料和 API Key 全部保存在你自己的浏览器里；只有你在点击「生成」时，提示词才会发送到**你自己配置的**模型服务商。

---

## 1. 谁在提供本扩展

码字工坊（Writer Studio）是一个独立开发的开源项目，以 MIT 许可证发布，源码公开在 GitHub 仓库中。本项目**不是**任何公司或第三方平台的产品，也与其无隶属关系。

---

## 2. 我们不收集什么

以下事项**全部没有**：

- ❌ 没有账号、没有登录
- ❌ 没有分析/统计（无 Google Analytics、无 Sentry、无任何埋点）
- ❌ 没有遥测、没有崩溃上报
- ❌ 没有广告、没有追踪器、没有第三方 Cookie
- ❌ 不读取、不修改你访问的网页（本扩展**没有内容脚本**）
- ❌ 不向开发者自己的服务器发送任何数据（本项目**没有服务器**）
- ❌ 不出售、不共享、不转让你的数据给任何第三方
- ❌ 不使用你的数据做广告、信用评估或任何与写作无关的用途

---

## 3. 哪些数据存在你自己的设备上

以下数据保存在浏览器的本地存储（IndexedDB，异常时降级为 localStorage），**不会离开你的设备**：

| 数据 | 说明 |
|---|---|
| 作品与章节正文 | 你写的全部稿件 |
| 设定卡片 | 大纲 / 角色 / 设定 / 伏笔，含伏笔文段 |
| 快照 | 你手动保存的版本 |
| 语料与检索索引 | 你采集的文本及本地 BM25 索引 |
| 设置 | 模型名、Base URL、温度、排版、主题等 |
| **API Key** | 你填写的模型密钥 |
| AI 调用日志 | 动作、模型名、字数、时间（用于你自己主动声明 AI 使用） |

**删除方式**：应用内的删除按钮、「清空语料」、浏览器的"清除站点数据"，或卸载扩展。删除后**不可恢复**，请自行导出备份。

---

## 4. 哪些数据会离开你的设备

**只有一个场景：你主动点击「生成」/「开始」时。**

此时，扩展会把下列内容通过 HTTPS 直接发送到**你自己在设置里配置的**模型服务商：

- 你的提示词（例如选中的正文片段、续写指令、当前章结尾）
- 在开启 RAG 注入时，命中的「风格画像 + 最相似的过往片段」
- 你配置的 API Key（作为请求头，用于该服务商鉴权）

**开发者看不到这些内容。** 请求由你的浏览器直接发往该服务商，不经过本项目任何中转服务器。

> 网页版（`serve.py`）下，请求会先经过你**本机**的 `127.0.0.1` 代理，再转发给模型服务商——这个代理只监听本机回环地址，其代码同样随本项目开源，你可自行审阅。

**第三方服务商**：你选择的模型提供方（如 DeepSeek、OpenAI、阿里云、智谱、月之暗面、硅基流动，或你自建的 OpenAI 兼容端点）会按其自身的隐私政策处理这些请求内容。**请阅读你所用服务商的条款**。若你使用本地 Ollama，则数据完全不出本机。

> ⚠️ **不点就不发**：不用 AI 功能时，本扩展不会产生任何网络请求。

## 5. 权限与用途

本扩展申请的权限都只为完成上面所说的功能，用途逐条列在
[权限说明](permission-justifications.md) 中。核心原则：**只申请必需的最小权限**，且不包含任何读取网页内容的权限。

---

## 6. 有限用途声明（Chrome Web Store Limited Use）

本扩展对你数据的使用**仅限于提供其公开的单用途功能**：本地优先的小说写作工作台。我们不会：

- 将你的数据传输给第三方，**除非**为提供该功能所必需（即你主动发起的模型调用）且你已明确配置；
- 将你的数据用于个性化广告；
- 将你的数据用于信用、借贷或保险评估；
- 出售你的数据。

---

## 7. 安全

- 本项目**没有服务器**，因此不存在"服务端泄露"这一风险面。
- API Key 以明文形式保存在浏览器的本地存储中，由浏览器的**同源隔离**机制保护。请勿在共用设备上保存密钥；如怀疑泄露，请到服务商处吊销并重新生成。
- 与模型服务商的通信使用 HTTPS。

---

## 8. 儿童隐私

本扩展不面向 13 岁（或你所在司法辖区规定的年龄）以下儿童，也不会有意收集儿童的任何信息。

---

本政策可能随版本更新调整。**以本仓库中的最新版本为准**；如有重大变更，会在版本说明中注明。
